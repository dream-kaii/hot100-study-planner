# Hot 100 学习工作台设计

## 目标

在现有 `hot100-study-planner` React/Vite 项目上改造出一个个人使用的 Hot 100 刷题工作台。应用保留现有题库、分类、每日计划、状态和备注能力，补充题目详情、代码随想录题解、Java/Python 代码、顺序/随机练习、倒计时、本地运行、错题复习和自动备份。

## 已确认的范围

- 直接改造现有公开项目，不重新搭建独立应用。
- 使用 React + Vite，保持轻量，不增加账号、云同步、多用户或线上后台。
- 页面改成干净的学习工具风格，移除当前红黑噪点、斜切背景和装饰性视觉。
- Hot 100 题目保留题号、标题、难度、专题和力扣链接。
- 题解优先搬运代码随想录中的文字、Java 和 Python 内容；代码随想录没有对应内容时使用力扣内容。页面保留来源链接和作者说明。
- 代码运行采用本机运行器：Python 使用 `python3`，Java 使用 `javac`/`java`，仅在本机执行。
- 第一版采用公开样例输入输出比较，不实现完整隐藏测试判题。
- 首次使用必须设置自动备份位置；之后状态变化自动写入备份文件，并支持一键导入。

## 总体架构

应用继续使用 Vite 开发服务器。React 页面负责题库、学习状态、倒计时和题解展示；本地存储负责快速恢复；IndexedDB 保存备份目录句柄；Vite 本地中间件负责调用本机 Java/Python 进程。不会部署远程 API，也不会把用户代码或学习数据上传到网络。

题目元数据存放在 `src/data/hot100.json`，题解、语言代码和公开样例放在独立的 `src/data/solutions.json`。题目 ID 是进度数据的稳定键，更新题目文字或来源不会清空已有学习记录。

## 页面与交互

### 首次设置

应用首次打开先展示设置页，要求用户选择备份文件夹。浏览器支持文件系统访问能力时，保存目录句柄并创建 `hot100-backup.json`；不支持时显示原因和 Chrome/Edge 建议。备份没有成功设置前，主刷题页面不可用。

### 首页

首页展示总进度、今日计划、到期复习、错题数量、各专题进度、最近备份时间和进入练习的按钮。今日计划沿用现有按时间、薄弱专题和每日新题上限生成的逻辑，并优先放入到期复习题。

### 题库

保留搜索、专题和状态筛选。列表显示题号、标题、难度、专题、状态和复习日期。点击题目进入详情页，不在表格里塞入大段文字。

### 题目详情与练习

详情页包含题目元信息、力扣链接、代码随想录链接、题解文字、复杂度、示例输入输出、Java/Python 标签、代码编辑区和练习状态操作。

练习模式支持按 Hot 100 顺序或随机选题，也支持只抽未开始、错题、到期复习题和指定难度。倒计时支持 15、25、45 分钟和自定义时长；刷新页面后恢复当前计时状态。计时结束只提示，不自动修改成绩。

### 错题与复习

状态包括“未开始、思考中、已完成、错题、待复习、已掌握”。错题记录错误原因和个人笔记。默认复习间隔为 1、3、7、14 天，用户重新完成题目后可推进下一次复习。

### 代码运行

题目详情中的“运行”请求发送到本机 Vite 中间件。运行器为每次执行创建临时目录，写入 Java 或 Python 源文件，执行编译/运行命令，设置 3 秒超时和 64KB 输出上限，再删除临时文件。前端显示编译错误、运行错误、标准输出和示例比较结果。

运行器只接受当前本机页面发起的请求，不提供远程访问入口。设置页显示 Java/Python 环境检测结果；缺少 JDK 或 Python 时给出安装提示。

第一版每道题至少提供一个公开样例，比较标准采用去除首尾空白后的文本比较。它用于快速检查代码能否运行并通过样例，不声称等价于力扣隐藏测试。

### 备份与恢复

学习状态在每次修改后先写入 `localStorage`，再以 1 秒防抖写入用户选择的 `hot100-backup.json`。备份内容包括题目状态、复习日期、备注、计时器、设置和数据版本号，不包括代码执行产生的临时文件。

设置页提供最近备份时间、立即备份、选择新位置、导入备份和导出备份。导入前让用户选择覆盖或合并；合并以题目 ID 为键，较新的更新时间获胜。读取旧版本数据时执行迁移，迁移失败则保留原文件并提示用户。

## 数据结构

每题的解题数据包含：

```js
{
  id: "1",
  summary: "哈希表记录目标值与下标。",
  java: "...",
  python: "...",
  examples: [{ input: "...", output: "..." }],
  complexity: { time: "O(n)", space: "O(n)" },
  solutionSource: "https://programmercarl.com/...",
  fallbackSource: "https://leetcode.cn/..."
}
```

学习状态沿用现有题目 ID 键，并增加 `reviewAt`、`mistakeType`、`updatedAt`、`lastRun` 字段。所有状态读写集中在 `src/services/storage.js`，复习日期计算集中在 `src/services/review.js`，备份句柄和文件读写集中在 `src/services/backup.js`。

## 文件边界

- `src/main.jsx`：应用路由状态和页面组合，保留现有每日计划计算。
- `src/components/`：题卡、题目详情、代码编辑器、计时器、备份面板和统计面板。
- `src/data/solutions.json`：Java/Python 题解和公开样例。
- `src/services/storage.js`：本地状态读写和数据迁移。
- `src/services/review.js`：状态变更和复习日期规则。
- `src/services/backup.js`：文件夹权限、自动备份、导入和导出。
- `vite.config.js`：仅增加本地代码运行中间件。
- `scripts/start.command`、`scripts/start.bat`：一键启动。
- `src/styles.css`：新的颜色、布局、响应式和状态样式。

## 明确不做

- 线上账户、云同步、多用户和远程后端。
- AI 自动讲题或自动生成学习计划。
- 将代码提交到力扣或其他第三方服务。
- 完整模拟力扣隐藏测试。
- 复制与学习无关的复杂 UI 框架和状态管理库。

## 验收标准

- `npm run build` 成功。
- 首次打开必须完成备份位置设置才能进入主页面。
- 修改状态、备注、复习日期后刷新页面，数据仍然存在。
- 自动备份文件能被重新导入，覆盖和合并结果正确。
- 顺序和随机练习都能按筛选条件选题。
- Java/Python 示例代码能运行，错误时能显示编译或运行信息。
- 计时器能开始、暂停、重置，刷新后状态合理恢复。
- 100 道题都能打开题目链接，并有题解来源或力扣备用来源。
