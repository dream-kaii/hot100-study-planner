# Current components

ProblemDetail receives question, solution, progressItem, note, onProgressChange, onNoteChange, onRun, onBack. It renders metadata, solution text, examples, notes, status buttons, Timer and CodeEditor. CodeEditor uses a lightweight textarea. Timer currently uses a reducer. BackupSetup and BackupPanel manage the mandatory folder backup. ProblemCard and ProgressPanel serve the bank/dashboard. React 19, Vite 7, lucide-react only.
